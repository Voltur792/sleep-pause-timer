# ⏰ Sleep Pause Timer

Простой и удобный таймер паузы для Windows: поставьте таймер, а когда он
дойдёт до нуля — программа нажмёт **media play/pause** (например, поставит
видео на паузу), **выключит ПК** или **усыпит** его.

Это десктоп-приложение для Windows. Есть версия в виде плагина
для AI-ассистента [Astra](https://github.com/mihailinl/AstraPlugins) —
см. репозиторий [SPT](https://github.com/Voltur792/SPT).

## Возможности

- ⏱ Таймер на часы / минуты / секунды с прогресс-баром
- ⏯ По завершении: нажатие media play/pause, выключение ПК или спящий режим
- ⏰ Будильник: срабатывает в заданное время, ежедневно или один раз, с повтором
  звонка через выбранный интервал; мелодия — любой аудиофайл (MP3, WAV, WMA, M4A)
  или системный звук Windows; расписание сохраняется и восстанавливается после
  перезапуска (`%APPDATA%\SleepPauseTimer\alarm.json`)
- 🪟 Активация выбранного окна перед нажатием клавиши — по подстроке заголовка
  или по номеру из списка найденных окон (`#N`), с обходом защиты фокуса
  Chromium-браузеров (Chrome, Edge, Яндекс.Браузер)
- 🔍 Поиск окон: кнопка «Найти окно» показывает нумерованный список всех окон
- 🌓 Светлая и тёмная темы с округлыми кнопками и мягким свечением при наведении;
  выбранная тема сохраняется после перезапуска
- ⏳ Отслеживание бездействия мыши и клавиатуры с предупреждением перед действием
- 🔄 Проверка и установка новых версий на вкладке «Обновления», с перезапуском
  приложения и сохранением расписания. Проверку при запуске можно включить по желанию
- 🫥 Сворачивание в трей (кнопкой «–» или закрытием окна) во время таймера,
  отслеживания бездействия или активного будильника — с индикатором состояния,
  отсчётом в тултипе, временем следующего звонка будильника и уведомлением
  из трея, когда будильник звонит при спрятанном окне
- Пауза / продолжить / отмена в любой момент

## Как использовать

1. На вкладке **«Таймер»** укажите часы, минуты и секунды, выберите действие
   и нажмите **«Запустить таймер»**. При необходимости выберите окно кнопкой
   **«Найти окно»**. Таймер можно приостановить, продолжить или отменить.
2. Для отслеживания бездействия задайте количество минут и нажмите
   **«Отслеживать бездействие»**. Оно запускается и останавливается отдельно от
   обычного таймера; одного ввода минут недостаточно для запуска.
3. На вкладке **«Будильник»** выберите время, дни недели и мелодию.
   Через **«Расписание на месяц»** можно задать несколько звонков на одну дату.
4. Переключайте тему кнопкой в правом верхнем углу.
5. На вкладке **«Обновления»** нажмите **«Проверить обновления»**, затем
   **«Скачать и установить»**, если доступна новая версия. Перед установкой
   остановите таймер, отслеживание бездействия и текущий звонок.

Обновление внутри программы доступно в EXE-сборке. Для перехода со старой версии
без этой вкладки скачайте новую сборку из Releases и запустите `sleep_pause.exe`.

## Запуск из исходников

Нужен Python 3.10+ (Windows):

```powershell
pip install -r requirements.txt
python sleep_pause.py
```

Для интерфейса нужен Pillow. Без `pyautogui` работают выключение и сон,
без `pystray` недоступно сворачивание в трей; поиск окон требует `pygetwindow`.

## Сборка exe

```powershell
pip install -r requirements.txt pyinstaller
pyinstaller sleep_pause.spec --noconfirm
# результат: dist\sleep_pause.exe
```

`sleep_pause.spec` автоматически подхватывает `app_icon.ico` / `app_icon.png`
из папки сборки (иконка окна и файла). Версия берётся из тега релиза
(`GITHUB_REF_NAME` в CI или последний локальный тег); для локальной сборки
следующего релиза задайте `SPT_BUILD_VERSION` с его тегом.
