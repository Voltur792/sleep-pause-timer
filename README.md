# ⏰ Sleep Pause Timer

Простой и удобный таймер паузы для Windows: поставьте таймер, а когда он
дойдёт до нуля — программа нажмёт **media play/pause** (например, поставит
видео на паузу), **выключит ПК** или **усыпит** его.

Это десктоп-приложение (Tkinter, один файл). Есть версия в виде плагина
для AI-ассистента [Astra](https://github.com/mihailinl/AstraPlugins) —
см. репозиторий [SPT](https://github.com/Voltur792/SPT).

## Возможности

- ⏱ Таймер на часы / минуты / секунды с прогресс-баром
- ⏯ По завершении: нажатие media play/pause, выключение ПК или спящий режим
- 🪟 Активация выбранного окна перед нажатием клавиши — по подстроке заголовка
  или по номеру из списка найденных окон (`#N`), с обходом защиты фокуса
  Chromium-браузеров (Chrome, Edge, Яндекс.Браузер)
- 🔍 Поиск окон: кнопка «Найти» показывает нумерованный список всех окон
- 🌓 Тёмная и светлая темы с анимированными кнопками
- 🫥 Сворачивание в трей (кнопкой «–» или закрытием окна) во время таймера
  или отслеживания бездействия — с индикатором состояния, обратным отсчётом
  в тултипе и предупреждением о бездействии через уведомление из трея
- Пауза / продолжить / отмена в любой момент

## Скачать

Готовый `.exe` (Windows x64, один файл, ничего устанавливать не нужно) —

## Запуск из исходников

Нужен Python 3.10+ (Windows):

```powershell
pip install -r requirements.txt
python sleep_pause.py
```

Все зависимости опциональны: без `pyautogui` работает выключение и сон,
без `pygetwindow` — поиск окон, без `pystray`/`pillow` — сворачивание в трей.

## Сборка exe

```powershell
pip install -r requirements.txt pyinstaller
pyinstaller sleep_pause.spec --noconfirm
# результат: dist\sleep_pause.exe
```

`sleep_pause.spec` автоматически подхватывает `app_icon.ico` / `app_icon.png`
из папки сборки (иконка окна и файла).
